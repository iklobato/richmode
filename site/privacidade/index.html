Política de privacidade

Atualizada em 11 de outubro de 2026.

Resumo

O app RichMode não coleta nenhum dado seu. Não temos servidor, não pedimos cadastro e não usamos ferramentas de análise, anúncios ou rastreamento.

O que fica no seu aparelho

O nome exibido, os valores, a moeda e o tema que você escolhe ficam guardados só no seu aparelho, para o app lembrar deles na próxima vez. Esses dados nunca são enviados para nós nem para ninguém. Para apagá-los, desinstale o app.

Permissões

O app não pede acesso a câmera, fotos, contatos, localização, microfone ou notificações.

Este site

O site richmode.app não usa cookies, formulários nem ferramentas de análise, e não carrega nada de outros sites. Ele é hospedado no GitHub Pages. O GitHub pode registrar o endereço IP de quem acessa, por segurança, conforme a declaração de privacidade do GitHub.

Crianças

O app não coleta dados de ninguém, incluindo crianças.

Mudanças

Se esta política mudar, a nova versão será publicada nesta página com a data atualizada.

Contato

Dúvidas sobre privacidade: suporte@richmode.app.
